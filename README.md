# MERN E-commerce Website

A full-stack e-commerce website built using the MERN stack with user authentication, product management, shopping cart, and checkout functionality.

## Features

- User authentication with Login, Sign Up, and Logout
- Add and remove products
- Add products to Cart
- Remove products from Cart
- Buy Now / Checkout functionality
- Delivery address entry during checkout

## Tech Stack

- MongoDB
- Express.js
- React.js
- Node.js
- Tailwind CSS
